## Git File Lifecycle

```text
+-------------------+
| Working Directory |
| (modified files)  |
+-------------------+
          |
          | git add
          v
+-------------------+
| Staging Area      |
| (index)           |
+-------------------+
          |
          | git commit
          v
+-------------------+
| Repository        |
| (commit history)  |
+-------------------+
```
